# team-dashboard (design sketch)

Not in the Maven reactor and does not compile. It shows where the API is heading, written in the shapes that already exist wherever they do. `examples/counter-spring` is the runnable demo.

Real today, and used here as they are: `ComponentTag`/`LiveComponent`, `setup()`, the create* functions of `j2act.Reactive`, `prop`, `action`, `withPreload`, `withThrottle`, `Store` and the rest of the core API. Not updated line by line for ADR 0031: it still shows where the API is heading, not code to copy.

Still design targets: `j2act.ui.Ui` (`UI.button`, `spinner`, `Variant`).
