## Next-run orientation

- Read `CLAUDE.md` for the project and validation workflows, and `docs/STYLE.md` for code style. In PowerShell, quote Maven properties containing dots, for example `'-Dgpg.skip=true'`, or the wrapper may receive `.skip` as a separate lifecycle phase.
- No-build clients publish only their unchanged `.client.js` entry. Their dependencies use public host URLs or globals from script tags in the initial shared layout. Vite handles JS and TS dependencies and publishes manifest-listed outputs; `npm run check` in `j2act-core` includes real Vite builds covering CommonJS, lazy chunks, assets and source maps.
