# Async primitives: query, generic mutation, upload factory

Signals cover synchronous state only; pending/error/retry/dedup need their own shape, borrowed from TanStack and hardened against Vaadin/LiveView/Uppy flaws. Queries are keyless by default with validated runs, and withKey(...) opts into shared cache identity (ADR 0020); mutation keys scope writes and wire withInvalidates refetching — no auto-linking. Mutation<V, R> is generic over any write: its body runs on the executor like a query loader and takes its inputs as the variables passed to mutate(v), never as State reads (ADR 0014), while status, data, error and variables commit on the lane, where onSuccess/onError also run. The latest mutate() owns the visible status; runs sharing a withKey(...) execute one at a time, in order. Retries back off exponentially off-lane. upload() preloads it with chunked resumable transport, server-enforced restrictions (never client-hint-only), UploadCtx naming over sanitized inputs, and framework-owned temp cleanup.

How upload() works. A file input's change event carries the picked file's name, size and type, and upload().mutate(e.file()) checks them against withMaxFileSize (10 MB by default) and withAccept, with the type guessed from the extension on the server where the JDK knows it. It then opens a temp part and hands the client a single-use URL. The client POSTs 512 KiB chunks with their byte offset and the session's CSRF token in X-J2-Token; requests with a foreign Origin are refused. Every answer carries the server's offset, so a dropped or repeated chunk resumes where the bytes actually stopped. Byte limits are enforced on what arrives, not on the claims. A complete file moves under withTarget with the withNaming name, which must resolve inside the target. Without a target the file stays in the framework's upload directory and is deleted with the session. Parts are deleted on failure, when the session ends, and after withUploadIdleTimeout without a chunk (2 minutes by default). Because the chunk endpoint checks its own token, a host running Spring Security's CSRF filter must exempt /_j2act/up/**.
